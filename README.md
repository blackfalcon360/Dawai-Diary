# 💊 Dawai Diary

A lightweight, offline-first Android medicine tracker built with Kotlin.

## Features
- Add, edit and delete medicine records
- Save medicine name, dose and usual time
- Log a dose as **Taken** or **Skipped**
- Daily overview and recent activity history
- Local on-device storage using SharedPreferences
- Emoji icons throughout the interface

## Build with GitHub Actions
1. Create a GitHub repository.
2. Upload the contents of this project to the repository (not the ZIP itself).
3. Open **Actions** and run **Build APK**, or push to `main`.
4. Download the `DawaiDiary` artifact from the completed workflow.

## Build locally
Open this folder in Android Studio and let Gradle sync, then run the `app` configuration.

## Important
This app is a personal record-keeping tool only. It does not prescribe medicines, verify doses, or replace a clinician's instructions. Confirm medicine names and doses with your healthcare professional. Data is stored locally on the device; uninstalling the app or clearing app data may erase it.
